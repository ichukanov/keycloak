== Настройка аутентификации

Эта глава описывает несколько тем аутентификации. Эти темы включают:

* Принудительная политика строгого пароля и одноразового пароля (OTP).
* Управление различными типами учетных данных.
* Вход через Kerberos.
* Отключение и включение встроенных типов учетных данных.
