== Управление сессиями пользователей

При входе пользователей в миры {project_name} поддерживает сеанс пользователя для каждого пользователя и запоминает каждый клиент, посещенный пользователем в ходе сессии. Администраторы Realm могут выполнять несколько действий при каждом сеансе пользователя:

* Просмотр статистики входа в реалм.
* Просмотреть активных пользователей и где они вошли в систему.
* Выход пользователя из сессии.
* Отозвать токены.
* Таймауты токенов.
* Настройка таймаутов сессий.
