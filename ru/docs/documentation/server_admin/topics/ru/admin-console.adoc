== Настройка областей

После того, как у вас есть административная учетная запись для консоли администратора, вы можете настроить реалмы. Область — это пространство, в котором вы управляете объектами, включая пользователей, приложения, роли и группы.  Пользователь принадлежит и вписывается в реалм.   Одно развертывание {project_name} может определять, хранить и управлять таким количеством миров, которое есть в базе данных.
