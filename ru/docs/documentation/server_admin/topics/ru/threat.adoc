[[mitigating_security_threats]]
== Смягчение угроз безопасности

Уязвимости безопасности существуют на любом сервере аутентификации. См. Internet Engineering Task Force's (IETF) https://datatracker.ietf.org/doc/html/rfc6819[OAuth 2.0 Threat Model] и https://datatracker.ietf.org/doc/html/draft-ietf-oauth-security-topics[OAuth 2.0 Security Best Current Practice] для получения дополнительной информации.
