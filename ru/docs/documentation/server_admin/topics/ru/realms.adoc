== Настройка областей

Область управляет набором пользователей, учетными данными, ролями и группами.  Пользователь принадлежит и вписывается в реалм.  Realms изолированы друг от друга
и могут управлять только и аутентифицировать контролируемых ими пользователей.  One {project_name} deployment can define, store, and manage as many realms
as there is space for in the database.  Принимая решение о наличии одного или нескольких миров о том, какую изоляцию вы хотите иметь для
ваших пользователей и приложений.  Например, вы можете определить область для сотрудников вашей компании и иметь отдельную область для своих клиентов.
Ваши сотрудники будут входить в область сотрудников и иметь возможность только просматривать внутренние приложения компании.  Customers would log into the customer
realm and only be able to interact with customer-facing apps.  В этом разделе вы узнаете некоторые основы создания и конфигурации Realm.
