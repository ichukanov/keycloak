== Управление OpenID Connect и SAML клиентами

[role="_abstract"]
Клиенты - это объекты, которые могут запрашивать аутентификацию пользователя.  Клиенты приходят в двух формах.
The first type of client is an application that wants
to participate in single sign-on.  Эти клиенты просто хотят, чтобы {project_name} обеспечил их безопасность.  Другой тип
клиента, который запрашивает токен доступа, чтобы он мог вызвать другие сервисы от имени аутентифицированного пользователя.
В этом разделе обсуждаются различные аспекты, связанные с настройкой клиентов и различными способами.
