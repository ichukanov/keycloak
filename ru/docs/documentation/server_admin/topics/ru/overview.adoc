== Функции и концепции {project_name}

{project_name} - это единый вход на решение для веб-приложений и RESTful веб-сервисов.  Цель {project_name} - упростить систему безопасности, чтобы разработчикам приложений было легко защищать приложения и службы, которые они развернули
в своей организации.  Функции безопасности, которые разработчики обычно должны писать сами по себе, предоставляются из коробки
и легко настраиваются под индивидуальные требования вашей организации.  {project_name} предоставляет настраиваемые
интерфейсы для логина, регистрации, администрирования и управления учетной записью.  Вы также можете использовать {project_name} как платформу интеграции
для привязки его к существующим серверам LDAP и Active Directory.  Вы также можете делегировать аутентификацию
сторонним поставщикам идентификационных данных, таким как Facebook и Google.
