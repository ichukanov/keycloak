== Настройка аудита для отслеживания событий

[role="_abstract"]
{project_name} включает в себя набор возможностей аудита. Вы можете записывать каждый логин и администратор действия и просматривать эти действия в консоли администратора. {project_name} также включает SPI слушателя, который слушает события и может инициировать действия. Примеры встроенных слушателей включают в себя лог файлы и отправку писем при возникновении события.
