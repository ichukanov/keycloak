== Создание первого администратора

После установки {project_name}вам нужна учетная запись администратора, которая может действовать как администратор _super_ с полными разрешениями на управление {project_name}. С этим счетом вы можете войти в консоль {project_name} администратора, где вы создаете области и пользователи и регистрируете приложения, защищенные {project_name}.

=== Создание учетной записи на локальном хосте

Если ваш сервер доступен с 'localhost', выполните эти шаги.

.Процедура
. В веб-браузере перейдите на http://localhost:8080{kc_base_path} URL.
. Введите имя пользователя и пароль, которые вы можете отозвать.
+
image:images/initial-welcome-page.png[Страница приветствия]

=== Создание учетной записи удаленно

Если вы не можете получить доступ к серверу с адреса `localhost` или просто хотите запустить {project_name} из командной строки используйте переменные окружения `KC_BOOTSTRAP_ADMIN_USERNAME` и `KC_BOOTSTRAP_ADMIN_PASSWORD` для создания первоначальной учетной записи администратора.

Например:

[source,bash]
----
export KC_BOOTSTRAP_ADMIN_USERNAME=<username>
export KC_BOOTSTRAP_ADMIN_PASSWORD=<password>

bin/kc.[sh|bat] start
----
