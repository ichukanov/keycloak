[[_recovery-codes]]
=== Код восстановления

Коды восстановления - это несколько последовательных одноразовых паролей (в настоящее время 12), автоматически сгенерированных {project_name} Коды могут быть использованы в качестве 2-го факторной аутентификации (2FA), добавив `Recovery Authentication Code Form` аутентификатор в ваш поток аутентификации. При конфигурировании в потоке {project_name} запрашивает у пользователя следующий сгенерированный код в порядке. Когда текущий код вводится пользователем, он удаляется и следующий код будет необходим для следующего входа.

По своей природе коды восстановления обычно работают в качестве резервной копии для других 2FA методов. Они могут дополнять `OTP Form` или `WebAuthn Authenticator`, чтобы дать возможность войти в систему внутри {project_name}, Например, если программное обеспечение или аппаратное устройство, используемое для предыдущих методов 2FA, нарушено или недоступно.

Вы можете настроить требуемое действие `Настроить OTP` для автоматического запроса кодов восстановления, включив *Добавить коды*.

==== Проверить код восстановления, требуемое действие включено

Проверьте действие кодов восстановления включено в {project_name}:

. Нажмите *Authentication* в меню.
. Нажмите на вкладку *Обязательные действия*.
. Убедитесь, что *Восстановление кодов* переключатель *Включено* имеет значение *Вкл*.

Переключите *Действие по умолчанию* на *Вкл*, если вы хотите, чтобы все новые пользователи регистрировали свои учетные данные кодов восстановления при первом входе в систему.

==== Настройте необходимые действия кодов восстановления

Из вкладки *Обязательные действия* в консоли администратора, вы можете настроить действие *Восстановление кодов*. До сих пор существует параметр конфигурации
*Предупреждение порог*. Когда пользователь имеет меньшее количество оставшихся кодов восстановления на его аккаунте, чем сконфигурированное здесь значение, консоль учетной записи покажет предупреждение пользователю, который будет
рекомендовать им установить новый набор кодов восстановления. Предупреждение, отображаемое пользователем, может выглядеть примерно так:

==== Добавление кодов восстановления к потоку браузера

Следующая процедура добавляет `Recovery Authentication Code Form` в качестве альтернативного способа входа в стандартный *Browser*.

. Нажмите *Authentication* в меню Realm.
. Нажмите на *Браузер* поток.
. Найди выполнение *Recovery Authentication Code Form* в подпотоке *Browser - Conditional 2FA*.
. Измените _requirement_ с _Disabled_ на _Alternative_ для этого выполнения.
+
image:images/recovery-codes-browser-flow.png[Восстановление потоков кодов браузера]
+
В этой конфигурации оба двухфакторных аутентификатора (`OTP Форма` и `Recovery Authentication Code Form`) являются альтернативными способами для входа в {project_name}. Если пользователь настроил оба типа учетных данных, учетные данные с наивысшим приоритетом будут отображаться по умолчанию, но при этом появится опция *Попробуйте еще один путь*, так что у пользователя есть альтернативные методы входа.

Вы можете увидеть больше примеров конфигураций 2FA в <<twofa-conditional-workflow-examples>>.

==== Создание учетных данных кодов восстановления

После включения необходимых действий по восстановлению кодов и управления типом учетных данных в потоке пользователи могут запросить создание своих собственных кодов. Это действие просто другое <<con-required-actions_server_administration_guide,required action>> которое может быть использовано в {project_name} (непосредственно вызвано пользователем с помощью Консоли Аккаунтов или назначено администратором с помощью Консоли Администратора).

Требуемое действие при выполнении генерирует список кодов и представляет их пользователю. Действие предлагает распечатывать, загружать или копировать список кодов, чтобы помочь пользователю сохранить их в безопасном месте. Для завершения настройки флажок *я сохранил эти коды где-то в безопасности* должен быть отмечен ранее.

image:images/recovery-codes-setup.png[Страница установки кодов проверки подлинности]

Коды восстановления могут быть пересозданы в любой момент.
