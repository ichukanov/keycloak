= Доступ к конечным точкам SCIM

Для всех конечных точек SCIM требуется авторизация с помощью токена владельца OAuth 2.0.

Неавторизованные запросы получают «401 Неавторизованный» ответ. Токен предъявителя должен также иметь соответствующие разрешения
для выполнения запрошенной операции.

Только конфиденциальные клиенты могут получить доступ к концевым точкам SCIM. Публичные клиенты не поддерживаются для вызовов SCIM API.

== Настройка клиента сервиса

Для доступа к SCIM API обычно создается конфиденциальный клиент с учетной записью сервиса в {project_name}.
Этот клиент получает токены доступа, используя предоставленные клиентом учетные данные.

.Процедура
. Нажмите *Клиент* в меню и нажмите *Создать клиент*.
. Установите *ID клиента* (например, `scim-client`) и нажмите *Далее*.
. Включите *Проверка подлинности клиентов* и *Роль учетных записей службы*, затем нажмите *Сохранить*.
. На вкладке *Учетные данные* отметьте *Клиентский секрет*.

== Назначение разрешений

Для доступа к ресурсам
должна быть предоставлена учетная запись сервиса, связанная с клиентом. Требуемые роли зависят от операций, которые необходимо выполнить клиенту.

.Процедура
. Нажмите *Клиенты* в меню, затем выберите созданный клиент.
. Нажмите на вкладку *Сервисный счет*.
. Нажмите *Назначить роль*, затем фильтровать по клиентам и выберите клиент `realm-management`.
. Назначить нужные роли, основанные на операциях, которые должен выполнить клиент.

SCIM API полагается на тот же <_admin_permissions,модель разрешений>> как на {project_name} Admin REST API. Если у учетной записи службы
уже есть роли администратора, необходимые для управления пользователями и группами через Администратор API, не требуется дополнительных настроек
для использования конечных точек SCIM.

If fine-grained admin permissions are enabled for the realm, access to SCIM resources can be further
restricted on a per-resource basis. Например, клиенту может быть предоставлено разрешение на просмотр только конкретных пользователей
или групп. Подробнее см. <_fine_grained_permissions,Fine-grained admin permissions>>.

В следующей таблице перечислены разрешения, необходимые для каждого типа операции SCIM:

[cols="1,1,2", options="header"]
|===
|Операция
|Необходимая роль
|Описание

|Создание, обновление, удаление пользователей
|`manage-users`
|Полный доступ к пользовательским ресурсам.

|Читать пользователей
|`view-users`
|Доступ к отдельным ресурсам пользователей только для чтения.

|Поиск пользователей
|`query-users`
|Возможность просматривать и фильтровать ресурсы пользователя.

|Создание, обновление, удаление групп
|`manage-users`
|Полноценный доступ к коллективным ресурсам.

|Чтение групп
|`view-users`
|Доступ только для чтения к отдельным групповым ресурсам.

|Поиск групп
|«группы запросов»
|Возможность перечислять и фильтровать групповые ресурсы.

|Обнаружение конечных точек доступа
|`query-users` или `query-groups`
|Доступ к `/ServiceProviderConfig`, `/ResourceTypes`, и `/Schemas`. Любая роль, подразумевающая `query-users` или `query-groups` (например, `view-users` или `manage-users`) также предоставляет доступ.
|===

The minimum set of roles required for full access to the SCIM API is `manage-users`, which covers all user and group
management operations as well as access to discovery endpoints.

== Настройка аудитории токенов

SCIM API проверяет, что токены доступа содержат правильную аудиторию (`aud`). Ожидаемая аудитория
является базовым URL-адресом SCIM API для этой сферы:

----
http://<host>:<port>/realms/<realm-name>/scim/v2
----

Токены без этой аудитории отвергаются ответом «401 Неавторизованный».

Чтобы настроить аудиторию, добавьте клиенту карту протокола *аудитория*:

.Процедура
. Нажмите *Клиенты* в меню, затем выберите созданный клиент.
. Щелкните на вкладку *Область клиента*, затем щелкните область действия для клиента (например, `scim-client-dedicated`).
. Нажмите *Настроить нового картографа*, затем выберите *Аудио*.
. Установите *Название* в описательное значение (например, `scim-audience`).
. В *Включенной пользовательской аудитории*, введите базовый URL-адрес SCIM API для вашего реалма (например, `\http://localhost:8080/realms/myrealm/scim/v2`).
. Убедитесь, что *Добавить токен* включен.
. Нажмите *Сохранить*.

Значение аудитории должно соответствовать базовому URL API SCIM, как показано {project_name}, включая схему, хост, порт,
и путь. Если {project_name} работает за обратным прокси, используйте URL интерфейса, настроенный через настройки имени хоста.

== Получение токена доступа

Для вызова SCIM API необходимо получить токен доступа, используя предоставленные учетные данные клиента:

[source,bash]
----
ACCESS_TOKEN=$(curl -s -X POST \
  http://localhost:8080/realms/myrealm/protocol/openid-connect/token \
  -d "grant_type=client_credentials" \
  -d "client_id=scim-client" \
  -d "client_secret=your-client-secret" \
  | jq -r '.access_token')
----

Затем используйте токен в заголовке `Authorization` при вызове конечных точек SCIM:

[source,bash]
----
curl http://localhost:8080/realms/myrealm/scim/v2/Users \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Accept: application/scim+json"
----
