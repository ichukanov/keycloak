SCIM (System for Cross-domain Identity Management) - это стандартный протокол, предназначенный для упрощения управления идентичностью между
несколькими системами и доменами. Определяется https://datatracker.ietf.org/doc/html/rfc7643[RFC 7643] (ore Schema) и
https://datatracker.ietf. rg/doc/html/rfc7644[RFC 7644] (Protocol), SCIM предоставляет общий набор REST API и схем
для создания, чтение, обновление и удаление идентификационных ресурсов, таких как пользователи и группы. Приняв SCIM, организации
могут автоматизировать предоставление и дезактивацию пользователей в своей инфраструктуре идентификации с использованием широко поддерживаемых библиотек и
.

и HR-системы, или другие провайдеры идентификации могут использовать эти стандартизированные API для обеспечения и управления пользователями в
{project_name} без использования патентного API Admin REST API.

В текущем выпуске реализация SCIM охватывает:

* **Управление пользователем**: Создание, чтение, обновление, патч и удаление ресурсов пользователя.
* **Управление группами**: Создание, чтение, обновление, исправление и удаление групповых ресурсов, включая управление членством.
* **Фильтрация и пагинация**: Искать ресурсы, используя полный синтаксис SCIM фильтра с поддержкой пагинации.
* **Расширения схемы**: Поддержка расширения пользователя предприятия (RFC 7643, раздел 4.3) и пользовательских схем через сопоставление атрибутов пользовательского профиля.
* **Поиск схемы**: Конечные точки для обнаружения поддерживаемых схем, типов ресурсов и возможностей сервера.

Будущие релизы планируется расширить поддержку SCIM с дополнительными возможностями, включая федерацию пользователей из внешних
поставщиков услуг SCIM и обновления событий в режиме реального времени на базе пушки.

The SCIM API is based on the same underlying user and group management functionality as the Admin REST API, ensuring
consistency in behavior and permissions. However, the SCIM API provides a standardized interface that can be easily
integrated with third-party tools and platforms that support SCIM.
