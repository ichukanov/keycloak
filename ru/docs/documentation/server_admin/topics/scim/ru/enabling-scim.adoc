[[_enabling_scim_]]
= Включение SCIM для области

Как только функция включена на сервере, вы также должны включить SCIM для каждой области в отдельности. Это можно сделать с помощью
консоли администратора или API REST администратора.

== Использование консоли администратора

.Процедура
. Нажмите *Настройки реалма* в меню.
. На вкладке *General* найдите переключатель *SCIM API*.
. Установите переключатель на *Вкл*.
. Нажмите *Сохранить*.

image:images/scim-realm-settings.png[alt="Включение SCIM API в настройках Realm"]

== Получение базового URL SCIM API

SCIM API в {project_name} выводится в соответствии со следующим базовым URL:

----
http://<host>:<port>/realms/<realm-name>/scim/v2
----

Этот базовый URL используется для создания полных URL-адресов доступных конечных точек SCIM:

* `/ServiceProviderConfig`
* `/Виды ресурсов`
* `/Schemas`
* `/Пользователи`
* `/группы`

Для SCIM API требуется токен предъявителя с соответствующими разрешениями. Смотрите <<_scim_accessing_endpoints_,Разрешение доступа к концам SCIM>>
для подробностей о настройке клиента и получении ключа доступа.
