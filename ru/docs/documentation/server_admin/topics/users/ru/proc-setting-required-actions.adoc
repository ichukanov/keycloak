= Настройка необходимых действий для одного пользователя

Вы можете установить необходимые для любого пользователя действия.

.Процедура
. Нажмите *Пользователи* в меню.
. Выберите пользователя из списка.
. Перейдите в список *Required User Action*.
+
image:images/user-required-action.png[]
. Выберите все действия, которые вы хотите добавить в аккаунт.
. Нажмите *X* рядом с названием действия, чтобы удалить его.
. Нажмите на кнопку *Сохранить* после того, как вы выберете действия для добавления.
