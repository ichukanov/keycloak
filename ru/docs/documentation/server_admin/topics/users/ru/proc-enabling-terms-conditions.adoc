= Включение условий и положений в качестве обязательного действия

Вы можете включить необходимое действие, которое новые пользователи должны принять условия перед входом в {project_name} в первый раз.

.Процедура
. Нажмите *Authentication* в меню.
. Нажмите на вкладку *Обязательные действия*.
. Включите действие *Условия и Положения*.
. Отредактируйте файл `terms.ftl` в основной теме входа.
