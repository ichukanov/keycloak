= Привязка пользователя

Администратор с соответствующими правами может имитировать пользователя. Например, если пользователь столкнулся с ошибкой в приложении, администратор может подменить пользователя для расследования или дублирования проблемы.

Любой пользователь с ролью "имперса" в реалме может олицетворить пользователя.

.Процедура
. Нажмите *Пользователи* в меню.
. Нажмите на пользователя, чтобы олицетворить.
. Из списка *Действия* выберите *Имперсоная*.
+
image:images/user-impersonate-action.png[]
* Если администратор и пользователь находятся в одной области, то администратор будет выходить из системы и автоматически войти в систему как пользователь импровизируется.
* Если администратор и пользователь находятся в разных сферах, администратор останется в системе, и дополнительно войдут в систему как пользователь в этом игровом мире.

В обоих случаях отображается *Консоль учетных записей* имперсонированного пользователя.

.Дополнительные ресурсы
* Для получения дополнительной информации о назначении администраторов обратитесь к главе <_admin_permissions,Admin Console Access Control>> .
