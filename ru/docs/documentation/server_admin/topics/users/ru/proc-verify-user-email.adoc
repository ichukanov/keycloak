= Проверка адреса электронной почты пользователя

[roles="_abstract"]
{project_name} может отправить подтверждение по электронной почте пользователю, чтобы подтвердить, что адрес электронной почты, который он зарегистрировал, действителен и доступен.
Это полезно при посадке новых пользователей или когда администратор хочет убедиться в правильности адреса электронной почты пользователя.

.Предпосылки
* Email настроен для реалма.
Смотрите <<_email, Настройка электронной почты для Realm>>.

//-

.Процедура
. Нажмите *Пользователи* в меню.
. Выберите пользователя, чей адрес электронной почты вы хотите проверить.
. Нажмите на вкладку *Учетные данные*.
. Нажмите *Удостоверение Reset* в правом верхнем углу.
. В диалоговом окне *Сброс учетных данных*, нажмите на раскрывающийся список *Сброс действий* и выберите *Проверить электронную почту*.
+
image::images/user-verify-email-credentials-reset.png[Credentials Reset dialog with Verify Email action selected]
. Необязательно: Установите срок действия в поле *Истекает в*.
. Нажмите *Send Email*.
+
{project_name} отправляет письмо пользователю, содержащее ссылку.
Пользователь должен нажать на ссылку, чтобы подтвердить право собственности на адрес электронной почты.

NOTE: Если пользователь не получает письмо с подтверждением, проверьте, правильно ли настроены параметры SMTP и что адрес электронной почты пользователя верен.
