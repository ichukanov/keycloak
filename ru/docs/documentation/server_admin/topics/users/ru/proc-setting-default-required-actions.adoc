= Настройка необходимых действий для всех пользователей

Вы можете указать, какие действия необходимы перед первым входом всех новых пользователей. Требования применяются к пользователю, созданному кнопкой *Добавить пользователя* на странице *Пользователи* или ссылкой *Регистрация* на странице входа.

.Процедура
. Нажмите *Authentication* в меню.
. Нажмите на вкладку *Обязательные действия*.
. Отметьте флажком в столбце *Установить как действие по умолчанию* для одного или нескольких обязательных действий. При первом входе нового пользователя необходимо выполнить выбранные действия.
