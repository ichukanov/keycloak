= Требование согласия пользователя с правилами и условиями при регистрации

[role="_abstract"]
Для регистрации пользователь может потребовать согласие с вашими условиями и условиями.

image:images/registration-form-with-required-tac.png[]

.Необходимые предпосылки
* Регистрация пользователей включена.
* Правила и условия обязательного действия включены.

//-

.Процедура
. Нажмите *Authentication* в меню.
Нажмите на вкладку *Блокировки*.
. Нажмите на *поток регистрации*.
. Выберите *Обязательные* в строке *Условия и Положения*.
