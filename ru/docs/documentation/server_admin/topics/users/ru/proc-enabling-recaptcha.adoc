[id="proc-enabling-recaptcha_{context}"]
= Включение reCAPTCHA

[role="_abstract"]
Для защиты регистрации от ботов {project_name} имеет интеграцию с Google reCAPTCHA (см. <<procedure_recaptcha>>) и reCAPTCHA Enterprise (см. <<procedure_recaptcha_enterprise>>).
Тема по умолчанию (`register.ftl`) поддерживает как v2 (visible, checkbox-based) и v3 (score-based, invisible) reCAPTCHA (см. https://docs.cloud.google.com/recaptcha/docs/choose-key-type[Выберите соответствующий тип ключа reCAPTCHA]).

[[procedure_recaptcha]]
== Настройка Google reCAPTCHA

. Введите следующий URL в браузере:
+
[source,bash,subs=+attributes]
----
https://www.google.com/recaptcha/admin/create
----
. Создайте reCAPTCHA и выберите между Challenge v2 (видимый флажок) или Score-based, v3 (невидимый) чтобы получить ключ reCAPTCHA сайта и секрет. Заметьте их для будущего использования в этой процедуре.
+
NOTE: домены localhost не поддерживаются по умолчанию. Если вы хотите и дальше поддерживать их на разработку, вы можете добавить их в список поддерживаемых доменов для ключа вашего сайта.
. Перейдите в консоль администратора {project_name}.
. Нажмите *Authentication* в меню.
. Нажмите на вкладку *Блокировки*.
. Выберите *Регистрация* из списка.
. Установите *reCAPTCHA* требование *Обязательно*. This enables
reCAPTCHA.
. Нажмите на иконку *передача* ⚙️ на строке *reCAPTCHA*.
+
image:images/recaptcha-config.png[]
.. Введите *reCAPTCHA Site Key*, созданный с сайта Google reCAPTCHA.
.. Введите *reCAPTCHA секрет*, созданный на веб-сайте Google reCAPTCHA.
.. Вкл/Выкл **reCAPTCHA v3** в соответствии с вашим типом ключа сайта: для reCAPTCHA на основе баллов (v3), выкл для вызова reCAPTCHA (v2).
.. (Необязательно) Переключить *Используйте recaptcha.net*, чтобы использовать `www.recaptcha.net` вместо домена `www.google.com` для cookies. Дополнительную информацию см. https://developers.google.com/recaptcha/docs/faq[reCAPTCHA faq].
. Авторизовать Google использовать страницу регистрации в качестве iframe.
+
NOTE: В {project_name}веб-сайты не могут включать в iframe диалог страницы входа. Это ограничение состоит в том, чтобы предотвратить атаку кликов. Необходимо изменить заголовки ответов HTTP по умолчанию, установленные в {project_name}.
.. Нажмите *Настройки реалма* в меню.
.. Нажмите на вкладку *Security Defenses*.
.. Введите `https://www.google.com` в поле заголовка *X-Frame-Options* (или `https//www.recaptcha.net`, если вы включите *Используйте recaptcha.net*).
.. Введите `https://www.google.com` в поле для заголовка *Content-Security-Policy* (или `https//www.recaptcha.net`, если вы включите *Используйте recaptcha.net*).

[[procedure_recaptcha_enterprise]]
== Настройка предприятия Google reCAPTCHA

. Введите следующий URL в браузере:
+
[source,bash,subs=+attributes]
----
https://developers.google.com/recaptcha/
----
. Создайте ключ для платформы «Website» и выберите нужный тип ключа. Оставьте значение по умолчанию для v3 reCAPTCHA (невидимый), или переключите *Используйте флажок вызова* для v2 reCAPTCHA (видимый). Обратите внимание на ключ сайта для будущего использования в этой процедуре.
+
NOTE: Локальный хост по умолчанию работает. Вам не нужно указывать домен.
. В вашем Google Cloud Project, перейдите на *Учетные данные* и создайте API ключ.
+
NOTE: Для большей безопасности нажмите на *отредактируйте ключ API* и добавьте ограничение API, чтобы ограничить ключ только *reCAPTCHA Enterprise API*.
. Перейдите в консоль администратора {project_name}.
. Нажмите *Authentication* в меню.
. Нажмите на вкладку *Блокировки*.
. Дублировать поток "регистрация".
. Привязка нового потока к *Регистрационному потоку*.
. Редактировать новый поток:
.. Удалите шаг *reCAPTCHA*.
.. Добавить шаг *reCAPTCHA Enterprise* в качестве подшага "регистрационной формы" (первый шаг потока).
. Установите требование *reCAPTCHA Enterprise* на *Required*.
. Нажмите на иконку *передача* ⚙️ на строке *reCAPTCHA Enterprise*.
+
image:images/recaptcha-enterprise-config.png[]
.. Введите *ID проекта Recaptcha* вашего проекта на Google Cloud.
.. Введите *Recaptcha Site Key*, созданный в начале процедуры.
.. Введите *Recaptcha API Key*, созданный в начале процедуры.
.. Вкл/Выкл **reCAPTCHA v3** в соответствии с вашим типом ключа сайта: для reCAPTCHA на основе баллов (v3), выкл для вызова reCAPTCHA (v2).
.. (Необязательно) Настройте *Min. Оценка порога* по своему усмотрению. Установите минимальный балл, между 0.0 и 1.0, чтобы пользователь мог зарегистрироваться на reCAPTCHA. См. https://docs.cloud.google.com/recaptcha/docs/interpret-assessment-website#interpret_scores[interpret scores].
.. (Необязательно) Переключить *Используйте recaptcha.net*, чтобы использовать `www.recaptcha.net` вместо домена `www.google.com` для cookies. Дополнительную информацию см. https://developers.google.com/recaptcha/docs/faq[reCAPTCHA faq].
. Авторизовать Google использовать страницу регистрации в качестве iframe. Смотрите последние шаги <<procedure_recaptcha>> для подробной процедуры.
