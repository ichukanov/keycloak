[id="proc-enabling-user-registration_{context}"]
= Включение регистрации пользователя

[role="_abstract"]
Разрешить пользователям самостоятельно регистрироваться.

.Процедура
. Нажмите *Настройки реалма* в главном меню.
. Нажмите на вкладку *Логин*.
. *Регистрация пользователей* на *ВКЛЮЧЕНИЕ*.

После того, как вы включите эту опцию, на странице входа в консоль администратора отображается ссылка *Регистрация*.
