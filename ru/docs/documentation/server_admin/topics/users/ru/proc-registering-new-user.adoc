= Регистрация как новый пользователь

[role="_abstract"]
Как новый пользователь, вы должны заполнить регистрационную форму для первого входа. Вы добавляете информацию о профиле и пароль для регистрации.

image:images/registration-form.png[]

.Необходимые предпосылки
* Регистрация пользователей включена.

//-

.Процедура
. Нажмите на ссылку *Регистрация* на странице входа. Отображена страница регистрации.
. Введите данные профиля пользователя.
. Введите новый пароль.
. Нажмите *Регистрация*.
