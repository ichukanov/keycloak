= Удаление пользователя

Вы можете удалить пользователя, которому больше не нужен доступ к приложениям. При удалении пользователя, профиль пользователя и данные также удаляются.

.Процедура
. Нажмите *Пользователи* в меню. Страница *Пользователи* отображается.
. Нажмите *Просмотреть всех пользователей*, чтобы найти пользователя для удаления.
+
NOTE: Кроме того, вы можете использовать строку поиска для поиска пользователя.
. Нажмите *Удалить* из меню действий рядом с пользователем, который вы хотите удалить и подтвердить удаление.
