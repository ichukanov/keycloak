= Определение учетных данных пользователя

Учётные данные пользователя можно управлять во вкладке *Учетные данные*.

image:images/user-credentials.png[учетные данные пользователя]

Вы меняете приоритет учетных данных перетаскиванием строк. Новый порядок определяет приоритет учетных данных для этого пользователя. Наивысшие учетные данные имеют высший приоритет. Приоритет определяет, какие учетные данные отображаются сначала после входа пользователя.

Тип:: В этом столбце отображается тип учетных данных, например *пароль* или *OTP*.
Метка пользователя:: Это метка, которую можно присвоить для распознавания учетных данных, когда они представлены в качестве опции выбора во время входа. It can be set to any value to describe the
credential.
Данные:: Это неконфиденциальная техническая информация о полномочиях. По умолчанию он скрыт. Вы можете нажать *Показать данные...* для отображения данных для учетной записи
.
Действия:: Нажмите *Сбросить пароль*, чтобы сменить пароль пользователя и *Удалить*, чтобы удалить учетные данные.

Вы не можете настроить другие типы учётных данных для определенного пользователя в консоли администратора; эта задача - ответственность пользователя.

Вы можете удалить учетные данные пользователя в том случае, если пользователь потеряет OTP устройство или если учетные данные были скомпрометированы. Вы можете удалить учетные данные пользователя только во вкладке *Учетные данные*.
