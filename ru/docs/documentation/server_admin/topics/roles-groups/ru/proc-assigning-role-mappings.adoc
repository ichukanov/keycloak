= Присвоение ролей

.Процедура
. Нажмите *Пользователи* в меню.
. Нажмите на пользователя, на который вы хотите сопоставить роли.
. Нажмите на вкладку *Сопоставления ролей*.
. Нажмите *Назначить роль*.
. Выберите роль, которую вы хотите назначить пользователю из диалогового окна.
. Нажмите *Назначать*.

image:images/user-role-mappings.png[Role mappings]

В предыдущем примере мы назначаем составную роль *разработчика* пользователю. Эта роль была создана в теме <_composite-roles, Composite Roles>>.

image:images/effective-role-mappings.png[Эффективные сопоставления ролей]

При назначении роли *Разработчика* роль *сотрудника* с составом *Разработчика* отображается с *Наследуемым* «Правда». *Наследуемые* роли являются ролями, которые явно назначаются пользователям и ролям, которые унаследованы от композитов.
