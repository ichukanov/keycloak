= Группы

Чтобы управлять группами, нажмите *Группы* в меню.

image:images/groups.png[]

Группы являются иерархическими. Группа может иметь несколько подгрупп, но группа может иметь только один родитель. Подгруппы наследуют атрибуты и сопоставления ролей их родителей. Пользователи также наследуют атрибуты и сопоставления ролей от их родителей.

Если у вас есть родительская группа и дочерняя группа и пользователь, который принадлежит только дочерней группе, пользователь в дочерней группе наследует атрибуты и сопоставления ролей как родительской группы, так и дочерней группы.

Иногда иерархия группы указывается по пути к группе. Путь - полный список имен, представляющих иерархию конкретной группы, сверху внизу и разделенные косой чертой `/` (схоже с файлами в файловой системе). Например, путь может быть `/top/level1/level2` означает, что `top` является группой верхнего уровня и является родительской частью `level1`, которая в свою очередь является родителем `level2`. Этот путь однозначно обозначает иерархию группы «level2».

По историческим причинам {project_name}не избегает слешей в самом названии группы. Поэтому группа названа `level1/group` под `top` использует путь `/top/level1/group`, который вводит в заблуждение. {project_name} может быть запущен с опцией `+--spi-group--jpa--escape-slashes-in-group-path+` к `true`, а затем слэш в имени слэш с символом `~`. Управляющие чары отмечают, что косой черт является частью названия и не имеет иерархического значения. Предыдущим примером пути будет `/top/level1~/group` при экране.

[source,bash]
----
bin/kc.[sh|bat] start --spi-group--jpa--escape-slashes-in-group-path=true
----

Ниже приведен пример группы «Продажи» верхнего уровня и подгруппы «Северная Америка».

Чтобы добавить группу:

. Нажмите на группу.
. Нажмите *Создать группу*.
. Введите название группы.
. Нажмите *Создать*.
. Нажмите на название группы.
+
Отображается страница управления группами.
+
image:images/group.png[]

Атрибуты и сопоставления ролей унаследованы группами и пользователями, входящими в группу.

Чтобы добавить пользователя в группу:

. Нажмите *Пользователи* в меню.
. Нажмите на пользователя, на который вы хотите сопоставить роли. Если пользователь не отображается, нажмите *Просмотреть всех пользователей*.
. Нажмите *Группы*.
. Нажмите *Присоединиться к группе*.
. Выберите группу из диалогового окна.
. Выберите группу из *Доступных групп*.
. Нажмите *Присоединиться*.
+
image:images/user-groups.png[]

Чтобы удалить группу из пользователя:

. Нажмите *Пользователи* в меню.
. Нажмите на пользователя для удаления из группы.
. Нажмите *Выйти* на строке таблицы группы.

В этом примере пользователь _jimlincoln_ находится в группе _Северной Америки_.  Вы можете увидеть _jimlincoln_ во вкладке *Участники* для группы.
