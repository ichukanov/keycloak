= Создание роли области

изображение:images/roles.png[]

.Процедура
. Нажмите *Создать роль*.
. Введите *Имя Роли*.
. Введите *Описание*.
. Нажмите *Сохранить*.

Поле *Описание* может быть локализовано путем указания переменной подстановки с `$\{var-name}`. Локализованное значение настроено на вашу тему в файлах свойств тем. См. ссылку:{developerguide_link}[{developerguide_name}] для получения более подробной информации.
