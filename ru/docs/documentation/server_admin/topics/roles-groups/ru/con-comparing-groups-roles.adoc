= Группы по сравнению с ролями

<_composite-roles,Композитные Роли>> похожи на группы, обеспечивающие одинаковую функциональность. Разница между ними является концептуальной. Составные роли применяют модель разрешений к набору служб и приложений. Использовать комбинированные роли для управления приложениями и услугами.

Группы фокусируются на коллекциях пользователей и их ролях в организации. Использовать группы для управления пользователями.
