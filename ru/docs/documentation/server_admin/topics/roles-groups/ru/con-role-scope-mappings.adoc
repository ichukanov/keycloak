= Сопоставления рамок роли

Ограничить роли в токене доступа. Когда клиент запрашивает аутентификацию пользователя, токен доступа, он получает содержит только сопоставления ролей, которые явно указаны для области действия клиента. Результат заключается в том, что разрешения каждого отдельного токена доступа ограничены вместо того, чтобы предоставлять клиенту доступ ко всем разрешениям пользователя.

По умолчанию каждый клиент получает все сопоставления ролей пользователя.
Вы можете просмотреть сопоставления ролей для клиента.

.Процедура
. Нажмите *Клиент* в меню.
. Нажмите на клиенте, чтобы перейти к деталям.
. Щелкните на вкладке *Область клиентов*.
. Нажмите на ссылку в строке с _выделенной областью и картографией для этого клиента_
. Нажмите на вкладку *Scope*.

image:images/full-client-scope.png[Полный охват]

По умолчанию эффективными функциями в этой области являются все заявленные роли. Чтобы изменить поведение по умолчанию, переключите *Полные рамки* на *ВЫКЛ* и укажите конкретные роли, которые вы хотите в каждом клиенте.
Вы также можете использовать <<_client_scopes, клиентские рамки>> для определения одинаковых ролей рамок для набора клиентов.

image:images/client-scope.png[Частичная область применения]

Смотрите <_oidc_token_role_mappings, раздел соответствия роли токенов>> , чтобы узнать подробнее о алгоритме, добавляющем роли в токен.
