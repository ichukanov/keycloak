= Преобразование роли в составную роль

.Процедура
. Нажмите на кнопку *Realm Roles* в меню.
. Нажмите на роль, которую вы хотите преобразовать.
. В списке *Действия* выберите *Добавить ассоциированные роли*.

image:images/composite-role.png[Композитная роль]

Интерфейс выбора роли отображается на странице, и вы можете привязать уровень реалмов и роли клиента к составной роли, которую вы создаете.

В этом примере роль «должника сотрудника» привязана к составной роли *разработчика*.  Любой пользователь с ролью *разработчик* также наследует роль *сотрудника*.

[NOTE]
====
При создании токенов и утверждений SAML, любой композит также имеет связанные с этим роли, добавляемые к претензиям и утверждения ответа на аутентификацию, отправленные клиенту.
====
