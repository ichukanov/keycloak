[[_default_roles]]
==== Роли по умолчанию

[role="_abstract"]
Роли по умолчанию позволяют вам автоматически назначать сопоставления ролей пользователей при создании новых или импорте через
<_identity_broker, Identity Brokering>>.
Чтобы указать роли по умолчанию, перейдите в левое меню *Roles*, и нажмите на вкладку *Default Roles*.

image:images/default-roles.png[]

Этот скриншот показывает, что некоторые _роли_ по умолчанию уже существует.
