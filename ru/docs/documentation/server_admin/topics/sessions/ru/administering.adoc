=== Управляющие сессиями

Чтобы увидеть вид верхнего уровня активных клиентов и сессий в {project_name}, нажмите *Сессии* в меню.

image:images/sessions.png[вкладка сессий]

==== Выйти из всех активных сессий

Вы можете выйти из игры всех пользователей в реалме. Из списка *Действия* выберите *Выйти из всех активных сессий*. Все cookies SSO становятся недействительными. {project_name} уведомляет клиентов с помощью адаптера OIDC клиента {project_name} при выходе из системы. Клиенты, запрашивающие аутентификацию в активных сеансах браузера, должны войти в систему снова. Такие типы клиентов, как SAML не получают запрос на выход из бэк-канала.

[NOTE]
====
Нажатие на *Выход из всех активных сессий* не снимает токены невыполненного доступа. Нерешенные токены должны истекать естественно. Для клиентов, использующих адаптер клиента {project_name} OIDC, вы можете сделать push <_revocation-policy, политика отзыва >> отменить токен, но это не работает для других адаптеров.
====

==== Просмотр клиентских сессий

.Процедура
. Нажмите *Клиент* в меню.
. Нажмите на клиента, чтобы увидеть сеансы клиента.
. Нажмите на вкладку *Сессии*.
+
image:images/client-sessions.png[сессии клиента]
