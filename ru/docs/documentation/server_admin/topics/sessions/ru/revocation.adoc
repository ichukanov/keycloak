=== Аннулирование активных сессий

Если ваша система поставлена под угрозу, вы можете отозвать все активные сессии и маркеры доступа.

.Процедура
. Нажмите *Сессии* в меню.
. Из списка *Действия* выберите *Аннулирование*.
+
image:images/revocation.png[Revocation]
. Укажите время и дату, когда сессии или токены, выпущенные до этого времени и даты, недействительны с помощью этой консоли.
* Нажмите *Установите сейчас*, чтобы установить политику на текущее время и дату.
* Нажмите *Push*, чтобы отослать эту политику отзыва любому зарегистрированному OIDC клиенту с адаптером {project_name} OIDC.
