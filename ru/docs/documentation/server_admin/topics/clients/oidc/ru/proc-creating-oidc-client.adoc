= Создание клиента OpenID Connect

[role="_abstract"]
Чтобы защитить приложение, использующее протокол подключения OpenID, вы создаете клиента.

.Процедура
. Нажмите *Клиент* в меню.
. Нажмите *Создать клиент*.
+
image:images/add-client-oidc.png[Создать клиента]
. Установлен *Тип клиента* *OpenID Connect*.
. Введите *ID клиента*
+
Этот ID является буквенно-цифровой строкой, которая используется в OIDC запросах и в базе данных {project_name} для идентификации клиента.
. Придайте *Название* клиенту.
+
Если вы планируете локализовать это имя, задайте значение переменной строки. Например, строковое значение, такое как $\{myapp}.  См. ссылку:{developerguide_link}[{developerguide_name}] для получения дополнительной информации.
. Нажмите *Сохранить*.

Это действие создает клиента и приведёт вас во вкладку *Настройки*, где вы можете выполнить xref:con-basic-settings_{context}[Базовая конфигурация].
