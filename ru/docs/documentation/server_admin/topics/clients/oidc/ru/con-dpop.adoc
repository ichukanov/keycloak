= DPoP

{project_name} поддерживает **DPoP** (демонстрационное подтверждение владения) для привязки и обновления токенов к паре криптографических ключей, гарантировать, что они могут быть использованы только законным клиентом.

Подробные инструкции по настройке, применению и использованию DPoP внутри {project_name}, см. по ссылке:{securing_apps_dpop_link}[*Защита приложений с помощью руководства DPoP*].
