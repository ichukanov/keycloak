= Использовать дескриптор сущности для создания клиента

Страница Клиента включает опцию *Импорт клиента*.

image:images/import-client-saml.png[Импорт клиента SAML]

.Процедура
. Нажмите *Обзор*.
. Загрузить файл, содержащий информацию XML-дескриптора сущности.
. Просмотрите информацию, чтобы убедиться, что все настроено правильно.

Некоторые SAML клиентские адаптеры, такие как _mod-auth-mellon_, нуждаются в XML Entity Descriptor для IDP.  Вы можете найти этого дескриптора, перейдя по ссылке:

[source, subs="attributes"]
----
root{kc_realms_path}/{realm-name}/protocol/saml/descriptor
----

где _realm_ - это область вашего клиента.
