Используйте *Область по умолчанию клиента Realm * для определения наборов рамок клиента, которые автоматически связаны с вновь созданными клиентами.

Чтобы увидеть область видимости по умолчанию клиента кликните на вкладке *Клиентские Области* в левой части консоли администратора. В столбце *Назначенный тип*, вы можете указать, следует ли добавить определенную область деятельности клиента как
*Объем Клиента по умолчанию* или *Необязательный Объем клиента* только что созданным клиентам. Смотрите <<_client_scopes_linking, этот раздел>> для подробностей о том, какие области _default_ и _optional_ находятся в пределах границ клиента.

При создании клиента, при необходимости можно отвязать границы клиентской области по умолчанию. Это похоже на удаление <<_default_roles, по умолчанию>.
