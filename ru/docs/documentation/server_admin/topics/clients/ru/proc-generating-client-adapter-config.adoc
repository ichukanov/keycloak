= Создание конфигурации клиентского адаптера

{project_name} может создать конфигурационные файлы, которые вы можете использовать для установки клиентского адаптера в среде установки вашего приложения. Для OIDC и SAML поддерживается несколько типов адаптеров.

. Нажмите на меню _Action_ и выберите опцию *Загрузить конфигурацию адаптера*
+
image:images/client-installation.png[]
. Выберите *Опцию Формата*, для которой вы хотите создать конфигурацию.

Все клиентские адаптеры {project_name} для OIDC и SAML поддерживаются. Поддерживается mod-auth-mellon Apache HTTPD адаптер для SAML, а также стандартные файлы SAML дескрипторов сущностей.
