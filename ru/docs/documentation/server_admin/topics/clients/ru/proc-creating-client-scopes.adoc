Чтобы создать клиентскую область выполните следующие действия:

. Щелкните *Клиент* в меню.
+
image:images/client-scopes-list.png[]
. Нажмите *Создать*.
. Назовите область вашего клиента.
. Нажмите *Сохранить*.

Область _клиента_ похожа на обычные клиенты. You can
define <<_protocol-mappers, protocol mappers>> and <<_role_scope_mappings, role scope mappings>>. Эти сопоставления могут быть унаследованы другими клиентами и сконфигурированы для наследования из области действия клиента.
