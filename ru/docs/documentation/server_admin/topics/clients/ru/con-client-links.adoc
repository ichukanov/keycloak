= Ссылки клиента

Если клиент получает доступ к этой конечной точке, используя запрос HTTP GET`, {project_name} возвращает настроенный базовый URL-адрес для предоставленного клиента и реалма в виде `HTTP 307` (Временное перенаправление) в заголовке `Location`. В результате клиент должен знать только имя реалма и идентификатор Клиента для связи с ним. Это ненаправление позволяет избежать жесткого кодирования адресов на основе клиента.

В качестве примера можно привести "master" области и client-id "account":

[source,subs=+attributes]
----
http://host:port{kc_realms_path}/master/clients/account/redirect
----

Этот URL временно перенаправляется на: http://host:port{kc_realms_path}/master/account
