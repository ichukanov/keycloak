= Мастерская область

* `Master realm` - этот мир был создан для вас при первом запуске {project_name}. В нем содержится учетная запись администратора, созданная при первом входе в систему.  Используйте _master_ только для создания и управления мирами в вашей системе.
* `Другие реалмы` - эти миры создаются администратором в основной реалме. В этих мирах администраторы управляют пользователями в вашей организации и приложениями, которые им нужны. Эти приложения принадлежат пользователям.

image:images/master_realm.png[Realms и приложения]

Realms изолированы друг от друга и могут управлять только и аутентифицировать тех пользователей, которые они контролируют. Following this security model helps prevent accidental changes and follows the tradition
of permitting user accounts access to only those privileges and powers necessary
for the successful completion of their current task.

.Дополнительные ресурсы
* Смотрите <<_per_realm_admin_permissions, edicated Realm Admin Consoles>>>, если вы хотите отключить _master_ и определить учётные записи администратора в любом новом реалме. Каждый Realm имеет свою собственную собственную консоль администратора, которую вы можете войти в систему с помощью локальных учетных записей.
