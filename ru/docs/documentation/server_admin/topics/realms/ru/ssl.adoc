= Настройка SSL для области

В каждом реалме есть соответствующий режим SSL, который определяет требования SSL/HTTPS для взаимодействия с Realm.
Браузеры и приложения, которые взаимодействуют с Realm, соблюдают требования SSL/HTTPS, определенные режимом SSL или не могут взаимодействовать с сервером.

.Процедура
. Нажмите *Настройки реалма* в меню.
. Нажмите на вкладку *Общее*.
+
image:images/general-tab.png[Общая вкладка]
. Установить *Требовать SSL* к одному из следующих режимов SSL:
* *Внешние запросы*
Пользователи могут взаимодействовать с {project_name} без SSL до тех пор, пока они сохраняются с частными адресами IPv4, такими как `localhost`, `127. .0.1`, `10.x.x.x`, `192.168.x.x`, `172.16.x.x` или IPv6 link-local и unique-lock-addresses.
Если вы пытаетесь получить доступ к {project_name} без SSL с неличного IP-адреса, вы получите ошибку.
* *Нет*
{project_name} не требует SSL.  Этот выбор применим только в разработке, когда вы экспериментируете и не планируете поддерживать это развертывание.
* *Все запросы*
{project_name} требует SSL для всех IP-адресов.
