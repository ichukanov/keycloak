= Содействие интернационализации

Каждый экран интерфейса интернационализирован в {project_name}.  Язык по умолчанию является английским, но вы можете выбрать, какие языки вы хотите поддерживать, и какой язык
по умолчанию.

.Процедура
. Нажмите *Настройки реалма* в меню.
. Нажмите на вкладку *Локализация*.
. Включите *Интернационализацию*.
. Выберите языки, которые вы поддерживаете.
+
image:images/localization.png[Вкладка локализации]
+
При следующем входе пользователя, этот пользователь может выбрать язык на странице входа в систему, чтобы использовать для экрана входа в систему, Консоль аккаунта и консоль администратора.

== Выбор локали пользователя

Локальный селектор предлагает лучшую локализацию на доступной информации. Тем не менее, часто неизвестно, кто это пользователь. По этой причине локаль пользователя, прошедшего аутентификацию, запоминается в сохраненном cookie.

Логика для выбора локали использует первый из следующих доступных:

* Пользователь выбран - когда пользователь выбрал локаль, используя выпадающий список локали
* Профиль пользователя - когда есть аутентифицированный пользователь и пользователь имеет предпочтительный локаль
* Выбран клиент - передается клиентом, используя например ui_locales параметр
* Cookie - последняя локаль, выбранная в браузере
* Принятый язык - локаль из заголовка *Accept-Language*
* Стандартный реалм
* Если ни один из вышеперечисленных, вернитесь на английский

При аутентификации пользователя запускается действие для обновления локали в указанных ранее сохраненных cookie. Если
пользователь активно переключил локаль через селектор локали на страницах входа, локаль пользователей также обновляется в
этой точке.

Если вы хотите изменить логику для выбора локали, у вас есть возможность создать пользовательский `LocaleSelectorProvider`. For details, please refer to the
link:https://www.keycloak.org/ui-customization/themes[Working with themes: Locale selector].
