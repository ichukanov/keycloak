= Настройка тем

Для данного мира вы можете изменить внешний вид любого пользовательского интерфейса в {project_name} , используя темы.

.Процедура
. Нажмите *Настройки реалма* в меню.
. Нажмите на вкладку *Темы*.
+
image:images/themes-tab.png[Themes tab]
. Выберите тему для каждой категории пользовательского интерфейса и нажмите *Сохранить*.
Тема для входа:: Ввод пароля для пользователя, OTP, регистрации новых пользователей и других аналогичных экранов, связанных с входом.
Тема учетной записи:: Консоль, используемая пользователем для управления своей учетной записью.
Тема консоли администратора:: Облик консоли администратора {project_name}.
Тема письма:: Каждый раз, когда {project_name} должен отправлять письмо, он использует шаблоны, определенные в этой теме для создания электронной почты.
