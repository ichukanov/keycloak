= Создание области

[role="_abstract"]
Вы создаете реалм, чтобы предоставить пространство для управления, где вы можете создавать пользователей и давать им разрешения на использование приложений. При первом входе вы обычно находитесь в _master_ области верхнего уровня, из которой вы создаете другие миры.

При решении вопроса о том, какие области вам необходимы, учитывайте тип изоляции, который вы хотите иметь для ваших пользователей и приложений.  Например, вы можете создать мир для сотрудников вашей компании и отдельный мир для ваших клиентов.
Ваши сотрудники будут входить в область сотрудников и иметь возможность только просматривать внутренние приложения компании.  Customers would log into the customer
realm and only be able to interact with customer-facing apps.

.Процедура
. В консоли администратора нажмите *Создать реалм* рядом с *Текущий реалм*.
. Введите имя для реалма.
. Нажмите *Создать*.
+
image:images/create-realm.png[Создать реалм]
+
Текущий реалм установлен в только что созданный реалм. Вы можете переключиться между мирами, нажав на название области в меню.
