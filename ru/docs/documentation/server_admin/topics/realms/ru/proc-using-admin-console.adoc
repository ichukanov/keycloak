== Использование консоли администратора

Вы настраиваете миры и выполняете большинство административных задач в консоли администратора {project_name}.

Чтобы использовать консоль администратора, вам нужна учетная запись администратора.

* Если администраторов не существует, см. xref:creating-first-admin_{context}[Создание первого администратора].
* Если другие администраторы существуют, попросите администратора предоставить доступ к учетной записи для управления реалмами.

//-

.Процедура
. Перейдите на URL консоли администратора.
+
Например, для localhost, используйте этот URL: http://localhost:8080{kc_admins_path}/
. Введите имя пользователя и пароль, которые вы создали на странице Welcome или через переменные окружения, как описано в https://www.keycloak.org/server/configuration#_creating_the_initial_admin_user[Создание начального пользователя администратора].
+
image:images/login-page.png[Страница входа]
+
Это действие отображает консоль администратора.
+
image:images/admin-console.png[консоль администратора]
. Обратите внимание на меню и другие параметры, которые вы можете использовать:
* Нажмите *Текущий реалм*, чтобы увидеть, доступны ли другие игровые миры.
* Нажмите *Создать реалм*, чтобы создать другой реалм, которым вы можете управлять.
* Нажмите на верхний правый список, чтобы просмотреть ваш аккаунт или выйти из аккаунта.
. Нажмите *Настройки реалма* в меню, чтобы увидеть поля и параметры для этого реалма.
+
Нажмите на значок вопроса *?*, чтобы показать определение такого поля как *Frontend URL*.
+
image:images/realm-settings.png[Настройки реалма]

[NOTE]
====
Экспорт файлов из консоли администратора не подходит для резервных копий или передачи данных между серверами. Только экспорт загрузок подходит для резервных копий или передачи данных между серверами.
====
