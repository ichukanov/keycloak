==== OIDC URI сервера {project_name}

[role="_abstract"]
Ниже приведен список конечных точек OIDC, которые {project_name} публикует. Эти конечные точки могут быть использованы, если не клиентский адаптер{project_name} использует OIDC для связи с сервером аутентификации. Это относительные URL. Корень URL-адреса состоит из протокола HTTP(S), имени хоста и опционально пути: Например

[source, subs="attributes"]
----
https://localhost:8080{kc_base_path}
----

/realms/{realm-name}/protocol/openid-connect/auth:: Используется для получения временного кода в коде авторизации Flow или получения токенов с помощью Implicit Flow, Direct Grants, или Клиентских грантов.
/realms/{realm-name}/protocol/openid-connect/token:: Используется кодом авторизации потока для преобразования временного кода в токен.
/realms/{realm-name}/protocol/openid-connect/logout:: Используется для выполнения выхода.
/realms/{realm-name}/protocol/openid-connect/userinfo:: Используется для информации о пользователе, описанной в спецификации OIDC.
/realms/{realm-name}/protocol/openid-connect/revoke:: Используется для отозвания токена OAuth 2.0, описанного в https://datatracker.ietf.org/doc/html/rfc7009[RFC 7009].
/realms/{realm-name}/protocol/openid-connect/certs:: Используется для набора ключей JSON Web (JWKS) с открытыми ключами, используемыми для проверки любого JSON Web Token (jwks_uri)
/realms/{realm-name}/protocol/openid-connect/auth/device:: Используется для предоставления разрешения устройства, чтобы получить код устройства и код пользователя.
/realms/{realm-name}/protocol/openid-connect/ext/ciba/auth:: Это конечная точка URL для канала аутентификации Клиента, инициированного для получения auth_req_id, которая идентифицирует запрос на аутентификацию, сделанный клиентом.
/realms/{realm-name}/protocol/openid-connect/logout/backchannel-logout:: Это конечная точка URL для выполнения выходов из бэкканала, описанная в спецификации OIDC.

Во всех этих разделах заменить {realm-name} на имя реалма.
