= Понимание языка выражения рабочего процесса

Некоторые параметры из определения рабочего процесса могут быть определены с помощью языка логического выражения, языка рабочего процесса.
Выражения определяются функциями, операторами и логическими операторами. The functions available in an expression will
depend on the setting where it is being defined.

Функции могут иметь нулевой или более аргументов, и они могут быть объединены со следующими логическими операторами и символами для определения сложных выражений
:

[cols="2*", options="header"]
|===
|Оператор
|Описание

|`и` |Логический `AND`

|`или` |Логический `ИЛИ`

|`не` |Логический `NOT`

|`()` |Группировка и разделение условной логики
|===

Эти примеры являются допустимыми выражениями:

```yaml
f1
f1 and f2
not (f1 and f2)
(f1 and f2) or f3
```

Настройки поддерживающие выражения предоставляют свой собственный набор функций, как вы увидите в следующих разделах.
