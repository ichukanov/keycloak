= Управление рабочими процессами

Управление процессами может осуществляться через консоль администратора или API REST администратора.

Только администраторы Realm с соответствующими правами могут управлять рабочими процессами, так как они считаются чувствительными операциями.
Подробнее см. <<_understanding_different_types_realm_admins_,Понимание различных типов администраторов реалма>>.

== Управление рабочими процессами через консоль администратора

Для управления рабочими процессами через консоль администратора, вы можете выполнить следующие действия:

.Процедура
. Нажмите *Workflows* в меню.

image:images/workflows-empty-list.png[alt="Пустой список рабочих процессов"]

Если в вашем реалме еще нет созданных рабочих процессов, вы увидите пустой список. Для создания нового рабочего процесса нажмите *Создать*.

. Создание нового рабочего процесса
image:images/workflows-create.png[alt="Создание нового рабочего процесса"]

Это откроет экран создания рабочего процесса, где вы можете определить рабочий процесс с помощью YAML формата. Для сохранения рабочего процесса нажмите *Сохранить*.

После создания одного или нескольких рабочих процессов, они будут перечислены в списке рабочих процессов.

image:images/workflows-list.png[alt="Список рабочих потоков"]

Из списка рабочих процессов можно выполнить следующие действия:

* **Создать**: Нажмите *Создать рабочий процесс*, чтобы создать новый рабочий процесс.
* **Обновление**: Нажмите на имя существующего рабочего процесса, чтобы обновить его.
* **Включить/Выключить**: Используйте кнопку переключателя в колонке *Статус*, чтобы включить или отключить рабочий процесс.
* **Скопируйте **: нажмите на кнопку *Копировать* рядом с рабочим процессом, чтобы создать его копию. Это полезно, если вы хотите создать новый рабочий процесс, основанный на существующем.
* **Удалить**: Нажмите на *Удалить* рядом с рабочим процессом, чтобы удалить его.

=== Обновление рабочего процесса

Чтобы обновить рабочий процесс, нажмите на его имя в списке рабочих процессов. Это откроет рабочий процесс в режиме редактирования, где вы можете изменить его YAML определение.
После внесения изменений нажмите *Сохранить*, чтобы применить обновления.

При обновлении рабочих процессов, если у них есть запланированные шаги. In such cases, you are not able to change the step chain of a workflow
if there are active instances of the workflow being updated. Это ограничение введено для обеспечения целостности текущего рабочего процесса экземпляров
в тех случаях, когда обновление шаговой цепочки может привести к дорогостоящей операции миграции существующих экземпляров на новую цепочку шагов,
может повлиять на производительность системы, а также привести к несоответствиям и неожиданному поведению.

В будущих выпусках мы планируем внедрить более гибкий подход к обновлению рабочих потоков с помощью запланированных шагов, чтобы администраторам
было разрешено мигрировать ресурсы реалма, запланированные на конкретный шаг, на другой шаг в обновленном рабочем процессе.

На данный момент единственная опция - либо дождаться завершения всех активных экземпляров или удаления рабочего процесса и создать новый.
Note that deleting a workflow will also delete all its active instances, therefore, realm resources associated with those instances
will not be processed further, and they would need to be re-associated with a new workflow instance if needed.
