= Сопоставляющие претензии организации

запросы авторизации на сервер. When authenticating in the context of an organization, clients can request the `organization` scope to map information
about the organizations where the user is a member.

В результате этого токен будет содержать следующую претензию:

```json
"organization": {
  "testcorp": {
    "id": "42c3e46f-2477-44d7-a85b-d3b43f6b31fa",
    "attr1": [
      "value1"
    ]
  }
}
```

The organization claim can be used by clients (for example, from ID Tokens) and resource servers (for example, from access tokens)
to authorize access to protected resources based on the organization where the user is a member.

Область «организации» представляет собой встроенную необязательную область деятельности клиента.  Таким образом, по умолчанию эта область добавляется любому клиенту, созданному в реалме. Он также определяет карточку «Членство в Организации», которая контролирует сопоставление информации о членстве организации с токенами.

NOTE: По умолчанию идентификатор и атрибуты организации не включены в претензию организации. Чтобы включить их, отредактируйте карту и включите параметры *Добавить идентификатор организации* и *Добавить атрибуты организации*, соответственно.

image:images/organizations-add-org-attrs-in-claim.png[alt="Включая атрибуты в претензию организации"]

Область `organization` запрошена с использованием различных форматов:

[cols="2*", options="header"]
|===
|Формат
|Описание

|«Организация» |Карты одной организации, если пользователь является членом одной организации.
В противном случае, если участник нескольких организаций, пользователю будет предложено выбрать организацию при аутентификации в реалме.

|`organization:<alias>` |Привязка к определенной организации с указанным псевдонимом.
Множественные организации могут быть запрошены путем указания нескольких областей охвата, например `organization:org-a organization:org-b`.
Если любой из псевдонимов не соответствует существующей организации или пользователь не является участником, запрос будет отклонен.

|«Организация:*» |Карты для всех организаций, членом которых является пользователь.
|===

NOTE: Смешивание различных форматов рамок (например, `organization` с `organization:org-a`, или `organization:org-a` с `organization:*`) недопустимо и приведет к ошибке.

Подробнее о включении в токены групп организаций см. <<_managing_groups_,Managing groups>.
