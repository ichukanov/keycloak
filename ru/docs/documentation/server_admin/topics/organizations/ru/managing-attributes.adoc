= Управление атрибутами

Администратор может хранить дополнительные метаданные об организации, используя атрибуты. Атрибут организации — это пара ключ/значение, которая может содержать несколько строковых значений.

Для этого нажмите на вкладку *Атрибуты* и установите любой атрибут, предоставив ключ и значение.

Чтобы предоставить несколько значений для одного и того же атрибута и ключа просто добавьте другой атрибут с тем же ключом, но с другим значением.
