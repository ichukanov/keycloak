=== Доступные данные сессии пользователя

После входа пользователя из внешнего IDP {project_name} хранит данные о сеансе работы с пользователем, к которым можно получить доступ. Эти данные могут быть распространены на клиент, запрашивающий вход с помощью токена или утверждения SAML переданы обратно клиенту с помощью соответствующего клиентского картера.

идентификатор провайдера:: Алиас IDP брокера используется для входа в систему.
идентификатор поставщика:: IDP имя пользователя аутентифицированного на данный момент пользователя. Зачастую но не всегда то же самое, что и имя пользователя {project_name}. Например, {project_name} может связать пользователя john` с пользователем Facebook `john123@gmail.com`. В этом случае значение сессии пользователя - `john123@gmail.com`.

Вы можете использовать <<_protocol-mappers, Mapper>> типа `User Session Note` для распространения этой информации среди ваших клиентов.
