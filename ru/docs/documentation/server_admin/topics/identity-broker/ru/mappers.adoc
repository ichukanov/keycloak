[[_mappers]]
=== Сопоставление претензий и утверждений

Вы можете импортировать метаданные SAML и OpenID Connect из внешнего IDP, с которым вы аутентифицируетесь. После импорта вы можете извлечь метаданные профиля пользователя и другую информацию, чтобы сделать их доступными для ваших приложений.

Каждый пользователь вошел в свою область с помощью внешнего поставщика идентификаторов имеет запись в локальной базе данных {project_name} , На основе метаданных из утверждений и претензий SAML или OIDC.

.Процедура
. Нажмите на *Identity Providers* в меню.
. Выберите одного из поставщиков идентификации в списке.
. Нажмите на вкладку *Mappers*.
+
image:images/identity-provider-mappers.png[mappers]
. Нажмите *Добавить карт*.
+
image:images/identity-provider-mapper.png[identity provider mapper]
. Выберите значение для *Переопределения режима синхронизации*. Карта обновляет информацию о пользователе, когда пользователи неоднократно регистрируются в соответствии с этой настройкой.
.. Выберите *legacy*, чтобы использовать предыдущую версию {project_name}.
.. Выберите *Импорт* для импорта данных, из которых пользователь был впервые создан в {project_name} во время первого входа в {project_name} с определенным провайдером идентификации.
.. Выберите *force* для обновления данных пользователя при каждом входе пользователя.
.. Выберите *Наследование*, чтобы использовать режим синхронизации, настроенный в поставщике данных. Все остальные опции перезапишут этот режим синхронизации.
. Выберите карту из списка *Тип карты*. Наведите курсор на *Тип карты* для описания карты и конфигурации, чтобы войти для карта.
. Нажмите *Сохранить*.

Для утверждений на основе JSON, вы можете использовать точечную нотацию для вложения, и квадратные скобки для доступа к полей массива по индексу. Например, `contact.address[0].country`.

Чтобы исследовать структуру данных пользовательского профиля JSON, предоставленных социальными провайдерами, вы можете включить `DEBUG` уровня logger `org.keycloak.social.user_profile_dump` при запуске сервера.
