=== Получение внешних IDP токенов

С {project_name}можно хранить токены и ответы от процесса аутентификации с внешним IDP, используя параметр конфигурации «Store Token» на странице настроек IDP.

Код приложения может получить эти токены и ответы для импорта дополнительной информации пользователя или для безопасного запроса внешнего IDP. Например, приложение может использовать токен Google для использования других служб Google и REST API.

Для получения информации о том, как настраивать и использовать эту функциональность, см. ссылку:{developerguide_link}#_identity-brokering-apis-tokens[раздел для получения внешних ключей IDP от {developerguide_name}].
