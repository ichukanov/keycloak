=== Поставщики социальных идентификаторов

Провайдер социальной идентификации может делегировать аутентификацию доверенному и уважаемому аккаунту в социальных сетях. {project_name} включает поддержку социальных сетей, таких как Google, Facebook, Twitter, GitHub, LinkedIn, Microsoft и Stack Overflow.
