==== GitHub

Чтобы войти в GitHub, выполните следующую процедуру.

.Процедура
. Нажмите на *Identity Providers* в меню.
. Из списка *Добавить провайдера* выберите *Github*.
+
image:images/github-add-identity-provider.png[Add Identity Provider]
. Скопируйте значение *Redirect URI* в буфер обмена.
. В отдельной вкладке браузера https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/creating-an-oauth-app[создать OAuth app] или https://docs.github.com/en/apps/creating-github-apps/about-creating-github-apps/about-creating-github-apps[создать GitHub app]. Обратите внимание, что только GitHub приложения могут обновлять токены, в то время как OAuth приложения не могут обновлять токены.
.. Введите значение *Redirect URI* в поле *URL обратного вызова авторизации* при создании приложения.
.. Обратите внимание на *ID клиента* и *Секрет клиента* на странице управления вашего OAUTH приложения.
. В {project_name}вставьте значение `Client ID` в поле *Client ID*.
. В {project_name}вставьте значение `Client secret` в поле *Client Secret*.
. Включите *JSON Format* для извлечения внешних IDP токенов в формате JSON.
Обратите внимание, что это также необходимо для обновления токенов.
. Нажмите *Добавить*.
