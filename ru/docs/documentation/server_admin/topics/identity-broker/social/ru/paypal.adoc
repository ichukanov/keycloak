==== PayPal

.Процедура
. Нажмите на *Identity Providers* в меню.
. Из списка *Добавить провайдера* выберите *PayPal*.
+
image:images/paypal-add-identity-provider.png[Добавить поставщика идентификации]
. Скопируйте значение *Redirect URI* в буфер обмена.
. В отдельной вкладке браузера откройте https://developer.paypal.com/developer/applications[PayPal Developer area].
.. Нажмите *Создать приложение* для создания приложения PayPal.
.. Обратите внимание на *ID клиента* и *Секретарь Клиента*. Нажмите на ссылку *Показать*, чтобы просмотреть секрет.
.. Убедитесь, что установлен *Войти с помощью PayPal*.
.. В разделе Войти через PayPal нажмите *Дополнительные настройки*.
.. Установите значение поля *Возвращать URL* в значение *Redirect URI* из {project_name}. Обратите внимание, что URL-адрес не может содержать `localhost`. Если вы хотите использовать {project_name} локально, замените `localhost` в *Return URL* на `127. .0.1` и затем получить доступ к {project_name} , используя `127.0.0.1` в браузере вместо `localhost`.
.. Убедитесь, что отмечены поля *Полное имя* и *E-mail*.
.. Нажмите *Сохранить* и затем *Сохранить изменения*.
. В {project_name}вставьте значение `Client ID` в поле *Client ID*.
. В {project_name}вставьте значение `Secret key 1` в поле *Client Secret*.
. Нажмите *Добавить*.
