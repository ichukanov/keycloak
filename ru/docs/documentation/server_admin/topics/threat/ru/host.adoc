=== Хост

{project_name} использует публичное имя хоста несколькими способами, например, в полях создателя токена и URL-адреса в письмах для сброса пароля.

По умолчанию имя хоста происходит от заголовков запроса. Проверка не существует, чтобы убедиться, что имя хоста является допустимым. Если вы не используете балансировщик нагрузки или прокси, с {project_name} для предотвращения некорректных заголовков хостов, настройте допустимые имена хостов.

Интерфейс провайдера (SPI) узла предоставляет возможность конфигурировать имя хоста для запросов. Вы можете использовать этот встроенный провайдер для установки фиксированного URL-адреса для запросов фронтенда при разрешении backend запросов на основе URI запроса. Если встроенный провайдер не имеет необходимых возможностей, вы можете разработать индивидуальный провайдер.
