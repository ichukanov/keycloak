=== Неопределённая редирекция URI

Сделайте зарегистрированные редиректы Унифицированных Идентификаторов Ресурсов, как это осуществимо. Регистрация расплывчатых URI перенаправления для xref:con-oidc-auth-flows_{context}[Код авторизации] может позволить злоумышленникам олицетворить другого клиента с более широким доступом. Имперсование может произойти, если два клиента живут под одним доменом, например.

Вы можете использовать безопасное перенаправление uris для вашего реалма. Результат удостоверяется в том, что администраторы могут регистрировать только клиентов с определенным redirect-uris соответствующим различным требованиям, таким как требование о том, что URL-адрес не может иметь шаблоны в контекстном пути или может быть ограничен указанными разрешенными доменами. Смотрите <<_client_policies, Client Policies>> для получения подробной информации о том, как настраивать политику клиента с конкретным исполнителем.
