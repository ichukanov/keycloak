=== Предоставленный код авторизации

Для xref:con-oidc-auth-flows_{context}[OIDC Auth Code Flow], {project_name} генерирует криптографически сильное случайное значение для его кодов авторизации. Код авторизации используется только один раз для получения ключа доступа.

На <_timeouts, страница таймаутов>> в консоли администратора, вы можете указать длительность действия кода авторизации. Убедитесь, что длительность времени меньше 10 секунд, что достаточно длинное, чтобы клиент запросил токен из кода.

Вы также можете защитить от утечки кодов авторизации, применяя <_proof-key-for-code-exchange, Proof Key for Code Exchange (PKCE)>> к клиентам.
