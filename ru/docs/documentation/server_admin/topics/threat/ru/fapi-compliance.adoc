=== Соответствие FAPI

Чтобы убедиться, что {project_name} сервер проверит ваш клиент более безопасным и совместимым с FAPI, вы можете настроить клиентские политики
для поддержки FAPI. *FAPI* подробности описаны в разделе{securing_apps_link}[защита приложений]. Среди прочего, это обеспечивает лучшую безопасность
описанную выше, как требуется SSL для клиентов, защищённый редирект URI использовал и больше аналогичных передовых практик.
