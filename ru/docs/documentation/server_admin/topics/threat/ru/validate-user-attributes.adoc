[[validate_user_attributes]]
=== Проверка атрибутов пользователя

С функциональностью в <<user-profile>>администраторы могут ограничивать данные пользователей вводить для атрибутов, например, при регистрации пользователя или в консоли аккаунта.

Администраторы не должны разрешать неуправляемые атрибуты для пользователей, чтобы предотвратить добавление неограниченного количества атрибутов.
Атрибуты должны иметь проверку, которая ограничивает количество данных, введенных злоумышленниками.

При использовании регулярных выражений для проверки атрибутов пользователя, избегайте регулярных выражений, использующих чрезмерное количество памяти или процессора.
Подробности смотрите на https://owasp.org/www-community/attacks/Regular_expression_Denial_of_Service_-_ReDoS[OWASP's Regular expression Denial of Service] .
