=== Политики паролей

Убедитесь, что у вас есть комплексная политика паролей для принудительного выбора сложных паролей. Смотрите главу <_password-policies, Password Policies>> для получения дополнительной информации. Предотвратить угадывание пароля, установив сервер {project_name} для использования одноразовых паролей.
