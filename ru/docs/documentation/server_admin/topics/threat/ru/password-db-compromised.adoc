=== База паролей скомпрометирована

{project_name} не сохраняет пароли в необработанном тексте, а как хэшированный текст, используя алгоритм «PBKDF2-HMAC-SHA512». {project_name} выполняет итерации хэширования `210,000`, количество итераций, рекомендованных сообществом безопасности. Это число итераций хэширования может отрицательно сказаться на производительности, поскольку хеширование PBKDF2 использует значительное количество ресурсов процессора.
