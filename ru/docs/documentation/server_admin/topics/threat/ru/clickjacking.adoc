=== Кликвиный угон

Щелчок — это техника, позволяющая пользователям нажать на элемент пользовательского интерфейса, отличный от того, что понимает пользователи. Злонамеренный сайт загружает целевый сайт в прозрачный iFrame, накладывается на верхней части набора демпинговых кнопок, расположенных непосредственно под важными кнопками на целевом сайте. Когда пользователь нажимает на видимую кнопку, он нажимает на кнопку на скрытой странице. При помощи этого метода злоумышленник может украсть учетные данные пользователя и получить доступ к его ресурсам.

По умолчанию каждый ответ {project_name} устанавливает некоторые специальные HTTP заголовки, которые могут предотвратить это событие.
В частности, он устанавливает https://datatracker.ietf.org/doc/html/rfc7034[X-Frame-Options] и https://www.w3.org/TR/CSP/[Content-Security-Policy].
Вы должны взглянуть на определение обоих заголовков, так как есть много мелкого зерна доступа к браузеру, который вы можете контролировать.

В консоли администратора можно указать значения заголовков X-Frame-Options и Content-Security-Policy.

. Нажмите на пункт меню *Настройки реалма*.
. Нажмите на вкладку *Security Defenses*.

По умолчанию, {project_name} устанавливает только _одинаковую политику происхождения_ для iframes.
