== Включение запомнить меня

Введённый пользователь, закрывающий свой браузер, уничтожает сеанс, и этот пользователь должен снова войти в систему. Вы можете установить {project_name} , чтобы сеанс входа пользователя был открыт, если этот пользователь нажимает флажок _Запомнить_ при входе в систему. Это действие приводит к тому, что cookie для входа из сессионных файлов cookie используется только для сохранения cookie.

.Процедура
. Нажмите *Настройки реалма* в меню.
. Нажмите на вкладку *Логин*.
. Переключить *Запомнить меня* на *Вкл*.
+
image:images/login-tab-remember-me.png[Вход запомнить меню]
+
Когда вы сохраните этот параметр, на странице входа в Realm отображается поле `remember me`.
+
изображение:images/remember-me.png[Запомнить меня]

WARNING: Отключение опции "Запомнить меня" приведет к аннулированию всех сессий, созданных с помощью флажка "Запомнить меня", выбранного во время входа, требующего от пользователей повторного входа.
Все токены обновления, связанные с этими сессиями, также станут недействительными.

Сессии не будут аннулированы, если переключатель отключен, , но при использовании Cookie или токена, связанного с некорректным сеансом, или асинхронно в фоновом режиме.
Это означает, что отключение и повторное включение переключателя «Запомнить меня» не может быть использовано для аннулирования старых сессий.
